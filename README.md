# Sovereign Mini Datacenter

**Sovereign Mini Datacenter** is a self-powered, liquid-cooled micro-datacenter stack designed for complete data autonomy.

Developed by **Metatopia Studio**.

---

## 🛠️ System Overview

* **Hardware Core:** DGX Spark compute nodes, solar PV panels, high-density battery storage, and liquid cooling enclosure.
* **Software Stack:** Self-hosted open-source enterprise suite (Local LLMs, GitLab, OpenProject, NextCloud).

---
