# Mailcow — Self-Hosted Email Stack

Mailcow runs as a **separate but integrated** stack alongside the main Sovereign stack.
The mail protocols (SMTP/IMAP/POP3) bind directly to the host, while the web UI
(SOGo webmail + admin panel) is routed through the main Traefik instance.

## Architecture

```
 Internet
    │
    ├── :25/:465/:587 (SMTP)   ─► postfix-mailcow (direct bind)
    ├── :993/:995 (IMAP/POP3)  ─► dovecot-mailcow (direct bind)
    └── :80/:443 (Web UI)      ─► Traefik ─► nginx-mailcow
                                             ├── /  (SOGo Webmail)
                                             └── /admin (Mailcow Admin)
```

## Prerequisites

- Main Sovereign stack already running (`software/docker-compose.yml`)
- Ports 25, 465, 587, 993, 995 open on firewall and not in use
- A fully qualified domain name with correct DNS records (see below)
- Reverse DNS (PTR) record set by your ISP/hosting provider

## DNS Records Required

```dns
# Replace mail.yourdomain.com with your MAILCOW_HOSTNAME
mail.yourdomain.com.    A      <your-server-ip>

# MX record
yourdomain.com.         MX 10  mail.yourdomain.com.

# SPF
yourdomain.com.         TXT    "v=spf1 mx ~all"

# DKIM — generated by mailcow after first start, copy from admin panel
dkim._domainkey.yourdomain.com.  TXT  "v=DKIM1; k=rsa; p=..."

# DMARC
_dmarc.yourdomain.com.  TXT    "v=DMARC1; p=quarantine; rua=mailto:postmaster@yourdomain.com"

# Autodiscovery
autoconfig.yourdomain.com.  CNAME  mail.yourdomain.com.
autodiscover.yourdomain.com. CNAME  mail.yourdomain.com.
```

## Installation

### 1. Clone mailcow-dockerized

```bash
cd software/mailcow
git clone https://github.com/mailcow/mailcow-dockerized.git core
cd core
```

### 2. Generate mailcow.conf

```bash
# Interactive generator
bash generate_config.sh
# When prompted:
#   Hostname: mail.yourdomain.com
#   Timezone: Europe/Athens
```

Or copy and edit the template:
```bash
cp ../mailcow.conf.example core/mailcow.conf
# Edit MAILCOW_HOSTNAME, TZ, and other values
```

### 3. Disable mailcow's built-in nginx on ports 80/443

Add to `core/mailcow.conf`:
```bash
HTTPS_BIND=127.0.0.1
HTTPS_PORT=8443
HTTP_BIND=127.0.0.1
HTTP_PORT=8025
```

### 4. Connect to the sovereign_net Docker network

```bash
# Add to core/mailcow.conf:
COMPOSE_PROJECT_NAME=mailcow
```

Then edit `core/docker-compose.yml` (or use the override file):
```bash
cp ../docker-compose.override.yml core/docker-compose.override.yml
```

### 5. Start mailcow

```bash
cd core
docker compose up -d
```

### 6. Add Traefik route (from repo root)

The file `../docker-compose.mailcow-traefik.yml` adds Traefik labels.
Run it as an extension of the main stack:

```bash
cd software
docker compose -f docker-compose.yml -f mailcow/docker-compose.mailcow-traefik.yml up -d
```

Or add this to your shell alias in `.bashrc`:
```bash
alias sovereign-up='docker compose -f ~/sovereign-mini-datacenter/software/docker-compose.yml -f ~/sovereign-mini-datacenter/software/mailcow/docker-compose.mailcow-traefik.yml up -d'
```

### 7. First login

- Admin panel: `https://mail.yourdomain.com/admin`  
- Default credentials: `admin` / `moohoo`  
- **Change immediately after first login!**
- SOGo Webmail: `https://mail.yourdomain.com/SOGo`

### 8. Copy DKIM key to DNS

In the admin panel: **Configuration → Domains → DNS** — copy the DKIM TXT record to your DNS provider.

## Updating Mailcow

```bash
cd software/mailcow/core
bash update.sh
```

## Firewall Rules (UFW)

```bash
sudo ufw allow 25/tcp   comment 'SMTP'
sudo ufw allow 465/tcp  comment 'SMTPS'
sudo ufw allow 587/tcp  comment 'SMTP Submission'
sudo ufw allow 993/tcp  comment 'IMAPS'
sudo ufw allow 995/tcp  comment 'POP3S'
```

## Integration with Other Services

Once mailcow is running, update `.env` in the main stack to use mailcow as SMTP:

```bash
SMTP_HOST=mailcow-postfix   # Docker service name on sovereign_net
SMTP_PORT=587
SMTP_USER=notifications@yourdomain.com
SMTP_PASSWORD=your_mailbox_password
SMTP_FROM=noreply@yourdomain.com
```

This routes GitLab, Vaultwarden, Nextcloud, and OpenProject emails
through your own mailcow instance instead of an external SMTP provider.
